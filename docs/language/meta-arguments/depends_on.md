# depends_on

[INTENT: REFERENCE]

The `depends_on` meta-argument declares explicit dependencies that the expression graph cannot infer — for example when a resource depends on another without referencing its attributes. The official language tree carries this topic as a page of the [meta-arguments](overview.md) area.
