# Cloud integration

[INTENT: REFERENCE]

The `cloud` block in the `terraform` settings block: integration with TACOS (TF Automation and Collaboration Software) — remote execution, shared state, and collaboration features. The official language tree carries this topic as a page of the [settings](overview.md) area.
