# base64gzip

[INTENT: REFERENCE]

`base64gzip` compresses a string with gzip and then encodes the result in Base64 encoding.

## Signature

```hcl
base64gzip(str)
```

## Parameters

- `str` (`string`)

## Return type

`string`
