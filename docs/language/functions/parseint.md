# parseint

[INTENT: REFERENCE]

`parseint` parses the given string as a representation of an integer in the specified base and returns the resulting number. The base must be between 2 and 62 inclusive.

## Signature

```hcl
parseint(number, base)
```

## Parameters

- `number` (`dynamic`)
- `base` (`number`)

## Return type

`dynamic`
