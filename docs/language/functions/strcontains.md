# strcontains

[INTENT: REFERENCE]

`strcontains` takes two values: a string to check and an expected substring. The function returns true if the string has the substring contained within it.

## Signature

```hcl
strcontains(str, substr)
```

## Parameters

- `str` (`string`)
- `substr` (`string`)

## Return type

`bool`
