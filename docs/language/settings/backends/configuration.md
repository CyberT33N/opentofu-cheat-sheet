# Backend configuration (general)

[INTENT: REFERENCE]

The general backend configuration model: the `backend "<type>"` block inside the `terraform` settings block, partial configuration, and supplying the remaining values at initialization time through [`tofu init -backend-config`](../../../cli/init/overview.md). The official language tree carries this topic as a page of the [backends](overview.md) area.
