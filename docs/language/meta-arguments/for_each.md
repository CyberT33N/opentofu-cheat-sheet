# for_each

[INTENT: REFERENCE]

The `for_each` meta-argument creates one instance per element of a map or set of strings, addressable as `<addr>["<key>"]` with `each.key` and `each.value` available inside the block. The official language tree carries this topic as a page of the [meta-arguments](overview.md) area.
