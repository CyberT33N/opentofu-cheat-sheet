# regexall

[INTENT: REFERENCE]

`regexall` applies a regular expression to a string and returns a list of all matches.

## Signature

```hcl
regexall(pattern, string)
```

## Parameters

- `pattern` (`string`)
- `string` (`string`)

## Return type

`list(dynamic)`
