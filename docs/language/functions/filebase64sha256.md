# filebase64sha256

[INTENT: REFERENCE]

`filebase64sha256` is a variant of `base64sha256` that hashes the contents of a given file rather than a literal string.

## Signature

```hcl
filebase64sha256(path)
```

## Parameters

- `path` (`string`)

## Return type

`string`
