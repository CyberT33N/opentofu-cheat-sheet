# indent

[INTENT: REFERENCE]

`indent` adds a given number of spaces to the beginnings of all but the first line in a given multi-line string.

## Signature

```hcl
indent(spaces, str)
```

## Parameters

- `spaces` (`number`) — number of spaces to add after each newline character.
- `str` (`string`)

## Return type

`string`
