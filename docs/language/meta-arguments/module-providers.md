# module-providers

[INTENT: REFERENCE]

The `providers` meta-argument in a `module` block passes provider configurations from the calling module into a child module — including alias configurations for multi-region or multi-account setups. The official language tree carries this topic as a page of the [meta-arguments](overview.md) area.
