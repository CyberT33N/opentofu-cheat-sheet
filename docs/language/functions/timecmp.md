# timecmp

[INTENT: REFERENCE]

`timecmp` compares two timestamps and returns a number that represents the ordering of the instants those timestamps represent.

## Signature

```hcl
timecmp(timestamp_a, timestamp_b)
```

## Parameters

- `timestamp_a` (`string`)
- `timestamp_b` (`string`)

## Return type

`number`
