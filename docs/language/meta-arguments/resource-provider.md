# resource-provider

[INTENT: REFERENCE]

The `provider` meta-argument on a resource or data block selects which provider configuration manages that object — required whenever more than one configuration of the same provider exists. The official language tree carries this topic as a page of the [meta-arguments](overview.md) area.
