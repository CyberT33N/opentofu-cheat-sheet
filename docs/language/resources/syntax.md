# Resource syntax

[INTENT: REFERENCE]

The syntax of the `resource` block: block type `resource` with two labels (resource type and local name, together forming the address `<type>.<name>`), a body of provider-defined arguments, and the language-level [meta-arguments](../meta-arguments/overview.md). The official language tree carries this topic as a page of the [resources](overview.md) area.
