# replace

[INTENT: REFERENCE]

`replace` searches a given string for another given substring, and replaces each occurrence with a given replacement string.

## Signature

```hcl
replace(str, substr, replace)
```

## Parameters

- `str` (`string`)
- `substr` (`string`)
- `replace` (`string`)

## Return type

`string`
