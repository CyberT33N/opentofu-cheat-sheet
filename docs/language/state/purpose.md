# State purpose

[INTENT: REFERENCE]

Why state exists: it records the mapping between the objects declared in the configuration and the real infrastructure objects created from them, tracks metadata, and is the source for [`tofu output`](../../cli/output/overview.md) and plan diffs. The official language tree carries this topic as a page of the [state](overview.md) area.
