# endswith

[INTENT: REFERENCE]

`endswith` takes two values: a string to check and a suffix string. The function returns true if the first string ends with that exact suffix.

## Signature

```hcl
endswith(str, suffix)
```

## Parameters

- `str` (`string`)
- `suffix` (`string`)

## Return type

`bool`
