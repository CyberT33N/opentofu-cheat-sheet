# Operators

[INTENT: REFERENCE]

The arithmetic and logical operators of the OpenTofu language: arithmetic (`+`, `-`, `*`, `/`, `%`), comparison (`==`, `!=`, `<`, `>`, `<=`, `>=`), and logical (`&&`, `||`, `!`) operators. The official language tree carries this topic as a page of the [expressions](overview.md) area.
