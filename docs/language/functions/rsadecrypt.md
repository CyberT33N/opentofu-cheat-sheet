# rsadecrypt

[INTENT: REFERENCE]

`rsadecrypt` decrypts an RSA-encrypted ciphertext, returning the corresponding cleartext.

## Signature

```hcl
rsadecrypt(ciphertext, privatekey)
```

## Parameters

- `ciphertext` (`string`)
- `privatekey` (`string`)

## Return type

`string`
