# Module refactoring

[INTENT: REFERENCE]

Refactoring module structure without losing state: `moved` blocks for renamed or re-nested resources and modules, complementing the imperative [`tofu state mv`](../../../cli/state/mv/overview.md). The official language tree carries this topic as a page of the [module development](overview.md) area.
