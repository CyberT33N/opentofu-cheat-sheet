# startswith

[INTENT: REFERENCE]

`startswith` takes two values: a string to check and a prefix string. The function returns true if the string begins with that exact prefix.

## Signature

```hcl
startswith(str, prefix)
```

## Parameters

- `str` (`string`)
- `prefix` (`string`)

## Return type

`bool`
