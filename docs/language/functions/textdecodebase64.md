# textdecodebase64

[INTENT: REFERENCE]

The `textdecodebase64` function decodes a string that was previously Base64-encoded, and then interprets the result as characters in a specified character encoding.

## Signature

```hcl
textdecodebase64(source, encoding)
```

## Parameters

- `source` (`string`)
- `encoding` (`string`)

## Return type

`string`
