# filesha256

[INTENT: REFERENCE]

`filesha256` is a variant of `sha256` that hashes the contents of a given file rather than a literal string.

## Signature

```hcl
filesha256(path)
```

## Parameters

- `path` (`string`)

## Return type

`string`

Official documentation: [filesha256](https://opentofu.org/docs/language/functions/filesha256/)
