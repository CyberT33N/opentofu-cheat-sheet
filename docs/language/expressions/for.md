# For expressions

[INTENT: REFERENCE]

The `for` expression transforms one collection into another: `[for v in list : v.upper()]` for lists and `{ for k, v in map : k => v }` for maps and objects. The official language tree carries this topic as a page of the [expressions](overview.md) area.
