# filebase64sha512

[INTENT: REFERENCE]

`filebase64sha512` is a variant of `base64sha512` that hashes the contents of a given file rather than a literal string.

## Signature

```hcl
filebase64sha512(path)
```

## Parameters

- `path` (`string`)

## Return type

`string`
