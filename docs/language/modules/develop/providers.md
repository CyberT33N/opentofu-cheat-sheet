# Providers in module development

[INTENT: REFERENCE]

Provider handling when developing shared modules: declaring `required_providers` in the module and receiving configurations from the caller instead of configuring providers inside a reusable module. The official language tree carries this topic as a page of the [module development](overview.md) area.
