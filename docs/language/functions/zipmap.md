# zipmap

[INTENT: REFERENCE]

`zipmap` constructs a map from a list of keys and a corresponding list of values.

## Signature

```hcl
zipmap(keys, values)
```

## Parameters

- `keys` (`list(string)`)
- `values` (`dynamic`)

## Return type

`dynamic`
