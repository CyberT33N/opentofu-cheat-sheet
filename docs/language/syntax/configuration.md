# Configuration syntax

[INTENT: REFERENCE]

The native OpenTofu language syntax: blocks with a type, zero or more labels, and a body of arguments and nested blocks; arguments assigning values to names; expressions representing values. The official language tree carries this topic as a page of the [syntax](overview.md) area.
