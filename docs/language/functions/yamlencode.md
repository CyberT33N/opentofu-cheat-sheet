# yamlencode

[INTENT: REFERENCE]

`yamlencode` encodes a given value to a string using YAML 1.2 block syntax.

## Signature

```hcl
yamlencode(value)
```

## Parameters

- `value` (`dynamic`, nullable)

## Return type

`string`
