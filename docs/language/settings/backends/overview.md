# Backend configuration

[INTENT: NAVIGATION]

Backend configuration: where and how the [state](../../state/overview.md) of a configuration is stored. Each backend type below is one official documentation page of this area.

## Backend types

- [azurerm](azurerm.md) — Azure Resource Manager storage
- [consul](consul.md) — HashiCorp Consul
- [cos](cos.md) — Tencent Cloud Object Storage
- [gcs](gcs.md) — Google Cloud Storage
- [http](http.md) — a generic HTTP endpoint
- [kubernetes](kubernetes.md) — Kubernetes secrets
- [local](local.md) — the local filesystem (default)
- [oss](oss.md) — Alibaba Cloud Object Storage Service
- [pg](pg.md) — PostgreSQL
- [remote](remote.md) — a remote TACOS backend
- [s3](s3.md) — Amazon S3
