# Type constraints

[INTENT: REFERENCE]

Type constraints declare the expected type of an [input variable](../values/variables.md) (for example `type = list(string)`), so OpenTofu can validate and convert assigned values. The official language tree carries this topic as a page of the [expressions](overview.md) area.

## Official documentation

- [Type Constraints](https://opentofu.org/docs/language/expressions/type-constraints/)
