# State backends

[INTENT: REFERENCE]

Backends determine where state is stored and where operations execute — from the default local filesystem backend to remote stores. The configured backend is initialized by [`tofu init`](../../cli/init/overview.md); the individual backend types are documented in [settings/backends](../settings/backends/overview.md). The official language tree carries this topic as a page of the [state](overview.md) area.
