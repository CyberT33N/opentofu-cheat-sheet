# Module blocks

[INTENT: REFERENCE]

The syntax for calling a child module from a parent module: the `module` block with its `source` argument, input variable assignments, and the module meta-arguments ([providers](../meta-arguments/module-providers.md), [depends_on](../meta-arguments/depends_on.md), [count](../meta-arguments/count.md), [for_each](../meta-arguments/for_each.md)). The official language tree carries this topic as a page of the [modules](overview.md) area.
