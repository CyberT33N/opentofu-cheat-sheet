# Installation

[INTENT: NAVIGATION]

Installation guides for the OpenTofu CLI (`tofu`).

- [Windows](windows.md)
- [Ubuntu](ubuntu.md)

The official documentation publishes further installation methods: `.apk` (Alpine), `.deb` (Debian and derivatives), `.rpm` (Fedora, RHEL and derivatives), Snap (Ubuntu and derivatives), Homebrew (macOS and Linux), an OCI container image (GitHub Container Registry), and standalone archives for Linux, macOS, Windows, and FreeBSD. See the [official installation documentation](https://opentofu.org/docs/intro/install/).
