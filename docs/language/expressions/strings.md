# Strings

[INTENT: REFERENCE]

String literals in the OpenTofu language: quoted strings with `${ ... }` interpolation, and heredoc strings (`<<EOT` … `EOT`) for multi-line content. The official language tree carries this topic as a page of the [expressions](overview.md) area.

## Official documentation

- [String Literals and Templates](https://opentofu.org/docs/language/expressions/strings/)
