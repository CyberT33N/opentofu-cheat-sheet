# alltrue

[INTENT: REFERENCE]

`alltrue` returns `true` if all elements in a given collection are `true` or `"true"`. It also returns `true` if the collection is empty.

## Signature

```hcl
alltrue(list)
```

## Parameters

- `list` (`list(bool)`)

## Return type

`bool`
