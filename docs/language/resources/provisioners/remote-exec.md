# remote-exec provisioner

[INTENT: REFERENCE]

The `remote-exec` provisioner runs commands on a remote resource over a [connection](connection.md) — for example bootstrapping a machine after creation. The official language tree carries this topic as a page of the [provisioners](overview.md) area.
