# nonsensitive

[INTENT: REFERENCE]

`nonsensitive` takes a sensitive value and returns a copy of that value with the sensitive marking removed, thereby exposing the sensitive value.

## Signature

```hcl
nonsensitive(value)
```

## Parameters

- `value` (`dynamic`, nullable)

## Return type

`dynamic`
