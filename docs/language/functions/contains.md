# contains

[INTENT: REFERENCE]

`contains` determines whether a given list or set contains a given single value as one of its elements.

## Signature

```hcl
contains(list, value)
```

## Parameters

- `list` (`dynamic`)
- `value` (`dynamic`)

## Return type

`dynamic`
