# Local values

[INTENT: REFERENCE]

Local values assign a name to an expression inside a module, declared in a `locals` block and referenced as `local.<NAME>` — the deduplication surface for expressions used more than once. The official language tree carries this topic as a page of the [values](overview.md) area.
