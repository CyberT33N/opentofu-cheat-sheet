# Function calls

[INTENT: REFERENCE]

Function calls in expressions follow the general syntax of a function name followed by comma-separated arguments in parentheses — for example `max(5, 12, 9)`. The complete catalog of callable functions lives in the [functions](../functions/overview.md) area; behavior can be probed live with [`tofu console`](../../cli/console/overview.md). The official language tree carries this topic as a page of the [expressions](overview.md) area.
