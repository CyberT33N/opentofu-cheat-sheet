# templatefile

[INTENT: REFERENCE]

`templatefile` reads the file at the given path and renders its content as a template using a supplied set of template variables.

## Signature

```hcl
templatefile(path, vars)
```

## Parameters

- `path` (`string`)
- `vars` (`dynamic`)

## Return type

`dynamic`
