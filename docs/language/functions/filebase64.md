# filebase64

[INTENT: REFERENCE]

`filebase64` reads the contents of a file at the given path and returns them as a base64-encoded string.

## Signature

```hcl
filebase64(path)
```

## Parameters

- `path` (`string`)

## Return type

`string`

Official documentation: [filebase64](https://opentofu.org/docs/language/functions/filebase64/)
