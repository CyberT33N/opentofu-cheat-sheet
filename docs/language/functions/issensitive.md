# issensitive

[INTENT: REFERENCE]

`issensitive` takes any value and returns `true` if the value is marked as sensitive, and `false` otherwise.

## Signature

```hcl
issensitive(value)
```

## Parameters

- `value` (`dynamic`, nullable)

## Return type

`bool`

Official documentation: [issensitive](https://opentofu.org/docs/language/functions/issensitive/)
