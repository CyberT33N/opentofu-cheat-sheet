# slice

[INTENT: REFERENCE]

`slice` extracts some consecutive elements from within a list.

## Signature

```hcl
slice(list, start_index, end_index)
```

## Parameters

- `list` (`dynamic`)
- `start_index` (`number`)
- `end_index` (`number`)

## Return type

`dynamic`
