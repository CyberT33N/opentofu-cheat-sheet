# filesha1

[INTENT: REFERENCE]

`filesha1` is a variant of `sha1` that hashes the contents of a given file rather than a literal string.

## Signature

```hcl
filesha1(path)
```

## Parameters

- `path` (`string`)

## Return type

`string`
