# Provisioner syntax

[INTENT: REFERENCE]

Declaring provisioners inside a `resource` block: the `provisioner "<type>"` block, `when` (create/destroy time), and `on_failure` (continue/fail) behavior. The official language tree carries this topic as a page of the [provisioners](overview.md) area.
