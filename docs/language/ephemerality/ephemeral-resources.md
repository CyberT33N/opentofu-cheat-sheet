# Ephemeral resources

[INTENT: REFERENCE]

Ephemeral resources are resources with an ephemeral lifecycle: their values exist during a run but are never persisted to the OpenTofu state. The official language tree carries this topic as a page of the [ephemerality](overview.md) area.
