# References

[INTENT: REFERENCE]

References address values in expressions: resources (`aws_instance.example`), input variables (`var.name`), local values (`local.name`), module outputs (`module.name.output`), data sources (`data.type.name`), and the special symbols `count.index`, `each.key`/`each.value`, `self`, and `path.module`/`path.root`/`path.cwd`. The official language tree carries this topic as a page of the [expressions](overview.md) area.
