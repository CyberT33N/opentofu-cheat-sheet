# textencodebase64

[INTENT: REFERENCE]

`textencodebase64` encodes the unicode characters in a given string using a specified character encoding, returning the result base64 encoded because OpenTofu language strings are always sequences of unicode characters.

## Signature

```hcl
textencodebase64(string, encoding)
```

## Parameters

- `string` (`string`)
- `encoding` (`string`)

## Return type

`string`

Official documentation: [textencodebase64](https://opentofu.org/docs/language/functions/textencodebase64/)
