# Upgrading to OpenTofu v1.6

[INTENT: REFERENCE]

The upgrade guides area of the OpenTofu language documentation: upgrade guidance for OpenTofu releases. The official language tree currently carries this area as a single index page covering the upgrade to OpenTofu v1.6, the first release in the stable OpenTofu v1.0 series. OpenTofu v1.6 honors the v1.0 compatibility promises, but documents behavior changes outside those promises that may require additional upgrade steps — notably the Linux DNS resolver change (OpenTofu on Linux uses a built-in DNS resolver instead of the platform C library resolver).
