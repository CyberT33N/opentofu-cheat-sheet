# Module sources

[INTENT: REFERENCE]

The kinds of paths, addresses, and URIs valid in the `source` argument of a module block: local paths (`./modules/greeting`), registry addresses, Git and other VCS URLs, and generic HTTP(S) endpoints — plus version selection for registry modules. The official language tree carries this topic as a page of the [modules](overview.md) area.
