# JSON syntax

[INTENT: REFERENCE]

The JSON configuration variant: every native-syntax configuration has a JSON equivalent in `.tf.json` / `.tfvars.json` / `.tofu.json` files, mapping the block structure onto JSON objects. The official language tree carries this topic as a page of the [syntax](overview.md) area.
