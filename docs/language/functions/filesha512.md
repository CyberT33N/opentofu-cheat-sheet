# filesha512

[INTENT: REFERENCE]

`filesha512` is a variant of `sha512` that hashes the contents of a given file rather than a literal string.

## Signature

```hcl
filesha512(path)
```

## Parameters

- `path` (`string`)

## Return type

`string`
