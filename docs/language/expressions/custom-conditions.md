# Custom conditions

[INTENT: REFERENCE]

Custom conditions attach author-defined checks to a configuration: `precondition` and `postcondition` blocks, variable `validation` blocks, and the `check` block (see [checks](../checks/overview.md)). The official language tree carries this topic as a page of the [expressions](overview.md) area.
