# ephemeralasnull

[INTENT: REFERENCE]

`ephemeralasnull` replaces any ephemeral values in the given value with a null value of the corresponding type.

## Signature

```hcl
ephemeralasnull(value)
```

## Parameters

- `value` (`dynamic`, nullable)

## Return type

`dynamic`
