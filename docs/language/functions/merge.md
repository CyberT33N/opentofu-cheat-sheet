# merge

[INTENT: REFERENCE]

`merge` takes an arbitrary number of maps or objects, and returns a single map or object that contains a merged set of elements from all arguments.

## Signature

```hcl
merge(maps...)
```

## Parameters

- `maps` (`dynamic`, variadic, nullable)

## Return type

`dynamic`
