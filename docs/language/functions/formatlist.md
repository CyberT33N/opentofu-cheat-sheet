# formatlist

[INTENT: REFERENCE]

`formatlist` produces a list of strings by formatting a number of other values according to a specification string.

## Signature

```hcl
formatlist(format, args...)
```

## Parameters

- `format` (`string`)
- `args` (`dynamic`, variadic, nullable)

## Return type

`list(string)`
