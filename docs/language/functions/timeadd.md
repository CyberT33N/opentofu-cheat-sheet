# timeadd

[INTENT: REFERENCE]

`timeadd` adds a duration to a timestamp, returning a new timestamp.

## Signature

```hcl
timeadd(timestamp, duration)
```

## Parameters

- `timestamp` (`string`)
- `duration` (`string`)

## Return type

`string`
