# Remote state

[INTENT: REFERENCE]

Storing state remotely: shared, durable, and access-controlled state storage through a remote [backend](../settings/backends/overview.md) instead of the local filesystem — the precondition for team collaboration. The official language tree carries this topic as a page of the [state](overview.md) area.
