# uuidv5

[INTENT: REFERENCE]

`uuidv5` generates a name-based UUID, as described in RFC 4122 section 4.3, also known as a "version 5" UUID.

## Signature

```hcl
uuidv5(namespace, name)
```

## Parameters

- `namespace` (`string`)
- `name` (`string`)

## Return type

`string`

Official documentation: [uuidv5](https://opentofu.org/docs/language/functions/uuidv5/)
