# trimsuffix

[INTENT: REFERENCE]

`trimsuffix` removes the specified suffix from the end of the given string. If the string does not end with the suffix, the string is returned unchanged.

## Signature

```hcl
trimsuffix(str, suffix)
```

## Parameters

- `str` (`string`)
- `suffix` (`string`)

## Return type

`string`
