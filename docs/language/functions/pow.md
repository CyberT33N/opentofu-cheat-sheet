# pow

[INTENT: REFERENCE]

`pow` calculates an exponent, by raising its first argument to the power of the second argument.

## Signature

```hcl
pow(num, power)
```

## Parameters

- `num` (`number`)
- `power` (`number`)

## Return type

`number`
