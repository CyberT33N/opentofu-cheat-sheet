# Override files

[INTENT: REFERENCE]

Override files (`override.tf`, `*_override.tf`, and their JSON variants) merge over the base configuration files of a directory, overriding selected settings without editing the base files. The official language tree carries this topic as a page of the [files](overview.md) area.
