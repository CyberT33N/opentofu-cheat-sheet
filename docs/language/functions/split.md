# split

[INTENT: REFERENCE]

`split` produces a list by dividing a given string at all occurrences of a given separator.

## Signature

```hcl
split(separator, str)
```

## Parameters

- `separator` (`string`)
- `str` (`string`)

## Return type

`list(string)`
