# Version constraints

[INTENT: REFERENCE]

The version constraint syntax used for provider and module versions and for `required_version`: operators such as `=`, `!=`, `>`, `>=`, `~>` (pessimistic constraint), and comma-separated combinations. The official language tree carries this topic as a page of the [expressions](overview.md) area.
