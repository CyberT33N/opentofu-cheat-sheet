# yamldecode

[INTENT: REFERENCE]

`yamldecode` parses a string as a subset of YAML, and produces a representation of its value.

## Signature

```hcl
yamldecode(src)
```

## Parameters

- `src` (`string`)

## Return type

`dynamic`

Official documentation: [yamldecode](https://opentofu.org/docs/language/functions/yamldecode/)
