# reverse

[INTENT: REFERENCE]

`reverse` takes a sequence and produces a new sequence of the same length with all of the same elements as the given sequence but in reverse order.

## Signature

```hcl
reverse(list)
```

## Parameters

- `list` (`dynamic`)

## Return type

`dynamic`
