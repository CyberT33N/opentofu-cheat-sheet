# Sensitive data in state

[INTENT: REFERENCE]

Sensitive values in state: the state records attribute values in plain form, so sensitive values require protected storage — remote backends with access control and [state encryption](encryption.md). The official language tree carries this topic as a page of the [state](overview.md) area.
