# State encryption

[INTENT: REFERENCE]

State encryption protects the state at rest: OpenTofu can encrypt the state with configurable key providers and methods before the backend persists it. The official language tree carries this topic as a page of the [state](overview.md) area; the official `state/examples/encryption/` tree carries code samples (excluded from this mirror as code samples, not documentation endpoints).
