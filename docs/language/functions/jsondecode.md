# jsondecode

[INTENT: REFERENCE]

`jsondecode` interprets a given string as JSON, returning a representation of the result of decoding that string.

## Signature

```hcl
jsondecode(str)
```

## Parameters

- `str` (`string`)

## Return type

`dynamic`
