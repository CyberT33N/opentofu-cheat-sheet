# Provider configuration

[INTENT: REFERENCE]

The `provider` block configures a provider before use — endpoint URLs, regions, credentials — and `alias` creates additional named configurations of the same provider for multi-region or multi-account setups. The official language tree carries this topic as a page of the [providers](overview.md) area.
