# substr

[INTENT: REFERENCE]

`substr` extracts a substring from a given string by offset and (maximum) length.

## Signature

```hcl
substr(str, offset, length)
```

## Parameters

- `str` (`string`)
- `offset` (`number`)
- `length` (`number`)

## Return type

`string`
