# templatestring

[INTENT: REFERENCE]

`templatestring` processes the provided string as a template using a supplied set of template variables.

## Signature

```hcl
templatestring(data, vars)
```

## Parameters

- `data` (`string`)
- `vars` (`dynamic`)

## Return type

`dynamic`
