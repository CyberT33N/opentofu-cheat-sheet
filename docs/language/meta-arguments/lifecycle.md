# lifecycle

[INTENT: REFERENCE]

The `lifecycle` block customizes the resource lifecycle: `create_before_destroy`, `prevent_destroy`, `ignore_changes`, `replace_triggered_by`, and the precondition/postcondition hooks. The official language tree carries this topic as a page of the [meta-arguments](overview.md) area.
