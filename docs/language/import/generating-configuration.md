# Generating configuration

[INTENT: REFERENCE]

For import blocks, OpenTofu can generate the matching HCL configuration for imported resources that are not already present in the configuration — activated through the experimental `-generate-config-out=path` option of [`tofu plan`](../../cli/plan/overview.md). The official language tree carries this topic as a page of the [import](overview.md) area.
