# try

[INTENT: REFERENCE]

`try` evaluates all of its argument expressions in turn and returns the result of the first one that does not produce any errors.

## Signature

```hcl
try(expressions...)
```

## Parameters

- `expressions` (`dynamic`, variadic)

## Return type

`dynamic`

Official documentation: [try](https://opentofu.org/docs/language/functions/try/)
