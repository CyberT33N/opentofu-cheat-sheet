# local-exec provisioner

[INTENT: REFERENCE]

The `local-exec` provisioner runs a command on the machine running OpenTofu — not on the remote resource — for example to call out to local tooling during creation or destruction. The official language tree carries this topic as a page of the [provisioners](overview.md) area.
