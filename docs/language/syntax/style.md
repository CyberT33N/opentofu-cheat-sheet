# Style guide

[INTENT: REFERENCE]

The canonical OpenTofu code style: indentation, alignment, and formatting conventions. The style is enforced mechanically by [`tofu fmt`](../../cli/fmt/overview.md), which rewrites configuration files to the canonical format. The official language tree carries this topic as a page of the [syntax](overview.md) area.
