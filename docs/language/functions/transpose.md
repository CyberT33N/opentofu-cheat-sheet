# transpose

[INTENT: REFERENCE]

`transpose` takes a map of lists of strings and swaps the keys and values to produce a new map of lists of strings.

## Signature

```hcl
transpose(values)
```

## Parameters

- `values` (`map(list(string))`)

## Return type

`map(list(string))`
