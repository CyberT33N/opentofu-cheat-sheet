# csvdecode

[INTENT: REFERENCE]

`csvdecode` decodes a string containing CSV-formatted data and produces a list of maps representing that data.

## Signature

```hcl
csvdecode(str)
```

## Parameters

- `str` (`string`)

## Return type

`dynamic`
