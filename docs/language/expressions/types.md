# Types

[INTENT: REFERENCE]

The value types of the OpenTofu language: primitive types (`string`, `number`, `bool`), collection types (`list`, `set`, `map`), and structural types (`object`, `tuple`), plus the special values `null` and the dynamic type. The official language tree carries this topic as a page of the [expressions](overview.md) area.
