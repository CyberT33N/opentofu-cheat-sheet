# coalesce

[INTENT: REFERENCE]

`coalesce` takes any number of arguments and returns the first one that isn't null or an empty string.

## Signature

```hcl
coalesce(vals...)
```

## Parameters

- `vals` (`dynamic`, variadic, nullable)

## Return type

`dynamic`
