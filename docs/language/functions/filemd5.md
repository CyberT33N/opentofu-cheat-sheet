# filemd5

[INTENT: REFERENCE]

`filemd5` is a variant of `md5` that hashes the contents of a given file rather than a literal string.

## Signature

```hcl
filemd5(path)
```

## Parameters

- `path` (`string`)

## Return type

`string`

Official documentation: [filemd5](https://opentofu.org/docs/language/functions/filemd5/)
