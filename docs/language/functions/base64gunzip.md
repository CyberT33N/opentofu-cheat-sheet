# base64gunzip

[INTENT: REFERENCE]

`base64gunzip` decodes a Base64-encoded string and uncompresses the result with gzip.

## Signature

```hcl
base64gunzip(str)
```

## Parameters

- `str` (`string`)

## Return type

`string`
