# Remote state data

[INTENT: REFERENCE]

Reading another configuration's state: the `terraform_remote_state` data source (provided by the [built-in provider](../providers/builtin.md)) exposes another configuration's root-level outputs as read-only data — the decoupling seam between separately managed configurations. The official language tree carries this topic as a page of the [state](overview.md) area.
